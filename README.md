# SmartTour-BigData-Tomas
SmartTour quiere desarrollar una plataforma inteligente para analizar datos turísticos y mejorar la toma de decisiones mediante tecnologías IA.

## Tecnologías
- Python
- Docker
- JupyterLab
- Pandas
  
## Instalación
docker compose up

## Objetivo
Analizar demanda turística y crear cuadros de mando.
